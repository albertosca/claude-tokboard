# claude-tokboard

This repo is public. Every change from here on - code, comments, commit
messages, docs, test data - is written assuming a stranger reads it
today, not "after we decide to publish." Concretely:

- No absolute paths, other project names, or identifying details beyond
  Alberto's own already-public identity (his real name and GitHub handle
  are already in `LICENSE`, `plugin.json`, and every commit's author
  field by design - that's attribution, not a leak).
- No secrets, tokens, or credentials, ever - not even in a throwaway
  script or a `.bak` file that "won't get committed."
- Example data in docs/tests uses generic placeholders (`my-api`,
  `blog-site`, `/Users/username/...`), never a real project name.

See `docs/PUBLISHING.md` for how the repo actually goes public, and
`docs/superpowers/specs/2026-08-05-public-launch-polish-design.md` for
the original privacy-audit reasoning this extends.
